# 强化学习在项目中的作用

## 1. 为什么需要 RL

几何 IK（`p24grasp/kinematics/ik.py`）对每个指尖独立求解"指尖到物体表面"，
但只能构造**开口式包裹**：物体被放在手指*指向*的位置（z≈0.16），而这只手
真正能*包围*物体的位置是**拳心**（五指全屈曲指尖质心 z≈0.074，见
[FINDINGS.md](FINDINGS.md) 第 7 节）。实测几何 IK 的成功率为 **0%**
（物体 0.3 s 内飞出）。

RL 的作用：**学习"保持"策略**——观测物体状态，输出 16 个关节目标角，使物体
留在手中。策略隐式学会了几何 IK 学不会的东西：

- 物体应放在拳心、手指全屈曲方向收敛（而不是径向张开方向）；
- 拇指与四指**分开缩放**（拇指在拳心内侧，统一缩放会把它顶进物体）；
- 物体被手掌兜住后会沉降 5–7 cm，"握持"判据应是留在附近 + 静止，而不是
  钉在出生点。

## 2. MDP 定义（`p24grasp/env/grasp.py`）

| 项 | 定义 |
| --- | --- |
| 动作 `a` | 16 维 ∈ [−1,1]：反归一化为 16 个关节的**绝对目标角**写入 `data.ctrl`（position 执行器，与 IK 目标同语义） |
| 观测 $o$ | 80 维：16 关节角（按限位归一化）+ 16 角速度（$\dot q/10$，clip ±1）+ 16 上一动作 + 物体相对拳心位置（$/0.1$）+ 四元数 + 线速度（$/0.5$）+ 角速度（$/2$）+ 半径（$(r-0.03)/0.01$）+ 质量（$(m-0.85)/0.65$）+ shape one-hot + 15 指尖相对物体位置（$/0.15$） |
| 控制频率 | 100 Hz（每 5 个 2 ms 物理步决策一次） |
| 回合长度 | 400 决策步 = 4.0 s |

**域随机化**（reset 时采样）：半径 $U[0.025,\,0.040]\ \mathrm{m}$、质量 $U[0.2,\,1.5]\ \mathrm{kg}$、
中心 ±2 mm、圆柱轴倾角 ±8°、初速扰动、初始闭合度（拇指 $U[0.3,0.9]$、
四指 $U[0.75,1.0]$ × 全屈曲，各加 $\mathcal{N}(0,0.03)$ 噪声）。

## 3. 奖励函数

每步奖励：

$$
r = 0.6\,e^{-(d/0.08)^2}
  + 0.4\,e^{-(v/0.05)^2}
  + 0.3\,\frac{\min(n,3)}{3}
  - 0.05\,\overline{|\tau_i|}
  - 0.01\,\overline{|a_t - a_{t-1}|}
$$

其中 $d$ = 物体距拳心距离，$v$ = 物体线速度模长，$n$ = 接触物体且互异的
手部几何数，$\tau_i$ = 第 $i$ 个执行器力矩（按 ±1 N·m 归一），
$\overline{|\cdot|}$ 表示对 16 个执行器取平均。

终局：

$$
\text{掉落：}\ z < z_c - 0.05\ \text{或}\ d > 0.12 \ \Rightarrow\ -20\ \text{并提前结束}
$$$$
\text{成功：}\ d < 0.075,\ v < 0.05\ \text{m/s},\ n \ge 3 \ \Rightarrow\ +20
$$

**量级梯度**（实测）：完美保持 $\approx +438$ / 4 s；不做动作 $\approx +19$ 后掉落；
几何 IK ≈ 负分。奖励的形状特意把"成功"放在显著高于"挂机"的位置，且
"什么都不做"必掉落（物体无地板支撑），排除了惰性局部最优。

## 4. 训练与结果（`p24grasp/rl/`）

```bash
python scripts/train_grasp_rl.py --algo both --shape cylinder --timesteps 1000000
python scripts/eval_grasp_rl.py  --shape cylinder --algo both --episodes 50 --media 2
```

- 实现：stable-baselines3 PPO / SAC，MLP 256×2（Tanh），`VecNormalize`
  （观测 + 奖励归一化，评估/回放必须使用保存的 `vecnormalize.pkl`）
- 公平对比：两算法使用同一套带种子域随机化
- 50 个种子、确定性推理的评估结果：

| 模型 | 成功率 | 保持时长 | 平均接触 |
| --- | --- | --- | --- |
| cylinder / SAC | **0.52–0.77** | 3.1 s | 6.5 |
| cylinder / PPO | 0.46 | 3.01 s | 5.4 |
| sphere / PPO | 0.33–0.37 | 2.3–2.7 s | 4.4 |
| 几何 IK（基线） | **0.00** | 0 s | 0 |

SAC 样本效率明显更高（23.7 万步即达 0.49，PPO 需 100 万步）。

## 5. 策略在项目中的位置

| 用途 | 说明 |
| --- | --- |
| **球体抓取** | 标称握姿抓不住球（滚动逃逸），球体依赖策略——查看器 `--shape sphere --policy` 是球体的主要玩法 |
| **圆柱** | 包裹对齐摆放 + 标称握姿（确定性）比策略更稳（10/10）；策略作为可选增强 |
| **回放** | 桌面/网页查看器 `--policy` 加载模型，以训练同分布采样 episode、同 100 Hz 驱动；网页端随 episode 自动轮换 |
| **对比基线** | 评估管线（`rl/eval.py`）同时产出 JSON 报告与 PNG/MP4，证明"关节能跟到 IK 目标 ≠ 抓得住" |

**策略能做什么、不能做什么**：策略解决"给定初始位姿后如何保持"（4 s 时间窗
内成功率 33–77%），不解决长期保持（FINDINGS 第 10 节的几何蠕滑，包裹对齐 +
自动重抓才是长期方案），也不改变指尖可达半径 26 mm 的硬件上限。
